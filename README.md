# MunoWatch Clone

A responsive, modern clone of the **MunoWatch** website built using **HTML, CSS, and JavaScript**.
This project includes multiple pages such as the Home page, Login page, Sign Up page, Watch details page, and Account page.

## 📌 Pages Included

* **index.html** – Main landing page
* **login.html** – User login page
* **sign.html** – User sign-up/registration page
* **watch.html** – Watch showcase or product details page
* **account.html** – User account/profile page

---

## 🎨 Tech Stack

* **HTML5** – Structure of the site
* **CSS3** – Styling, layout, responsiveness
* **JavaScript (Vanilla)** – Interactivity and dynamic behavior

---

## 🚀 Features

* Clean, modern UI inspired by the original MunoWatch design
* Fully responsive layout for all devices
* Navigation across all major pages
* Simple form handling for login and signup
* Watch/product details page with images and descriptions
* Optional account page UI for user data

1. Clone the repository:
